# PRD: v1 PRD 02 장 일정, 데이터 검증, 기준가
> **상태**: 초안, 구현 전
> 상위 SPEC: [v1 SPEC](../SPEC.md)

## 의존성

- PRD 01의 저장 형식과 acceptance 실행기

## 문제

시뮬레이션은 날마다 어떤 시각의 봉이 있어야 하는지, 어느 봉이 동시호가인지, 그날 기준가와 분배금이 얼마인지 알아야 한다.
이것을 받은 데이터로 추정하면 빠진 봉을 늦은 개장으로 잘못 보거나 기업행사를 놓친다.

## 목표

1. 저장소에 커밋한 장 일정 표로 날짜별 예상 봉 시각과 동시호가 봉을 정한다(SPEC 3.3).
2. 저장된 캔들을 SPEC 3.4대로 검증하고, 어긴 것을 모두 모아 알린다.
3. 일봉 비율로 날짜별 기준가와 주당 분배금을 계산한다(SPEC 3.3).
4. 검증을 통과한 데이터를 PRD 03에 넘긴다.
5. 이후 PRD가 함께 쓰는 가상 시세 fixture 생성기를 만든다.

## 범위 밖

- 체결, 비용, 전략, 판정
- 장 일정 표에 없는 특별 장의 추정

| `src/rt_trading/market_data.py` | 캔들 검증, 기준가·분배금 계산, 검증된 데이터 |

## 장 일정

- 정상일(09:00~15:30)은 표에 넣지 않고 예외일만 넣는다.
- 데이터 기간의 예외일 후보다. 커밋 전에 KRX 공지로 하나씩 확인한다.

| 날짜 | 개장~마감 | 이유 |
| --- | --- | --- |
| 2023-01-02 | 10:00~15:30 | 연초 첫 거래일 |
| 2023-11-16 | 10:00~16:30 | 수능 |
| 2024-01-02 | 10:00~15:30 | 연초 첫 거래일 |
| 2024-11-14 | 10:00~16:30 | 수능 |
| 2025-01-02 | 10:00~15:30 | 연초 첫 거래일 |
| 2025-11-13 | 10:00~16:30 | 수능 |
| 2026-01-02 | 10:00~15:30 | 연초 첫 거래일 |

- 예상 봉 시각은 개장 1분 뒤부터 마감까지 1분 간격이다. 첫 봉은 시가 동시호가 봉, 마지막 봉은 종가 동시호가 봉이다.
- 종가 동시호가 접수 구간 봉은 마감 9분 전부터 1분 전까지의 봉이다(정상일 `15:21`~`15:29`).

## 검증

SPEC 3.4를 구현한다. 어긴 것을 모두 모아 날짜, 종목, 코드와 함께 출력한다.

| 코드 | 조건 |
| --- | --- |
| `V1_DATA_MISSING` | DB 파일이 없거나, 두 종목 중 하나라도 `candles_1m` 또는 `candles_1d`에 행이 없거나, 가장 늦은 `fetched_at`의 `fetch_runs` 네 행이 없다 |
| `V1_SESSION_MISMATCH` | 장 일정의 예상 봉이 빠졌거나, 그 밖의 시각 봉이 있다 |
| `V1_BAR_MALFORMED` | 시각 중복·역전, OHLC 불변식 위반, 음수 거래량 |
| `V1_AUCTION_VOLUME_ZERO` | 시가 또는 종가 동시호가 봉의 거래량이 0이다 |
| `V1_AUCTION_WINDOW_TRADED` | 종가 동시호가 접수 구간 봉에 거래량이 있다 |
| `V1_TRADING_DAY_MISMATCH` | 두 종목의 거래일이 다르거나, 일봉과 1분봉의 거래일이 다르다 |
| `V1_BASE_PRICE_INVALID` | 기준가가 전날 종가보다 2원 넘게 높거나 3% 넘게 낮다 |

## 기준가와 분배금

- SPEC 3.3의 식을 따른다. 데이터 첫 거래일은 준비일이라 계산하지 않는다.
- 결과는 날짜·종목별 기준가(원)와 주당 분배금(원, 없으면 0)이다.

## 검증된 데이터

PRD 03에 넘기는 것이다.

- 거래일 목록과 날짜별 장 일정
- 종목·거래일별 1분봉(시각 오름차순)
- 종목·거래일별 기준가와 주당 분배금

## 가상 시세 fixture

- fixture에는 날짜별 장 유형, 그날의 기본 가격과 거래량, 바꿀 봉만 적는다. 생성기가 나머지를 채운다.
- 적지 않은 봉은 직전 봉 종가를 시가·고가·저가·종가로 하고 기본 거래량(1 이상)을 넣는다. 종가 동시호가 접수 구간 봉은 거래량 0이다.
- 일봉은 1분봉에서 만든다. 수정 종가는 날짜별로 적은 비율(없으면 1)을 원가격 종가에 곱해 원 단위로 반올림한다.
- 생성기는 결과를 PRD 01과 같은 표 구조로 임시 SQLite 파일에 넣고, 고정된 `fetched_at`으로 `fetch_runs` 네 행도 넣는다. 검증은 실데이터와 같은 읽기 경로로 그 파일을 읽는다.
- 사례마다 기대값을 손으로 계산해 함께 적는다.

## 필수 Acceptance

SPEC 9절의 "데이터와 장 일정" 항목을 맡는다.

- 정상일 390개, 연초 첫 거래일 330개, 수능일 390개의 예상 봉 시각과 동시호가 봉 위치가 맞다.
- 위 표의 코드마다 그 조건을 어긴 사례가 있고, 그 코드로 실패하며 어긴 날짜를 모두 출력한다.
- 데이터 첫 거래일은 기준가 계산과 검증 없이 준비일로만 쓰인다.
- 기준가: 비율 공식, 0.5원 올림, 2원 이내 무변화, 분배락일 주당 분배금, 기준가 상승과 3% 초과 하락의 실패가 손 계산과 같다.
